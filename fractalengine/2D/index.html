what is this?

equation

what is this?

the rule applied at every pixel, every step. the colored zones below work like a code editor: names, numbers, functions and operators each get their own color as you type.

f(z) =
syntax reference

each pixel repeats z ← f(z). everything is a complex number.

names: z current value, c the fixed value, i, pi, e, plus any parameters you add below

operators: + − * / ^ and implicit multiplication (2z, 3(z+1))

functions: sin cos tan sinh cosh tanh exp log sqrt conj sqr recip, plus abs (absolute value of each part, as in the burning ship), mag (modulus), re, im, arg

try: z^2 + c/z^2, sin(z)*c + z^2, z - a*(z^3-1)/(3z^2)

parameters

what is this?

extra named numbers you can use inside the equation above. give each one a single-letter name, a range it can be dragged across, and — optionally — a range to sweep between automatically.

rendering

what is this?

controls for how the escape-time calculation itself runs: how many steps to try, how far a point must travel to count as "escaped", and how those steps turn into a picture.

250

the slider sets the count at the starting zoom; each ×10 of zoom adds 100 more, up to 4000.

32

keeps the centre at arbitrary precision and renders deep views by perturbation, so you can zoom far past where the gpu's floats run out. raise iterations as you go deeper.
